This power enables Jira and Sumo MCP capabilities using **locally installed**
MCP servers.

This power does **not** bundle or install MCP servers.  
It assumes the servers are already present on your machine.

---

## Requirements

You must install the MCP servers separately before using this power.

See the setup guide in the `steering/` folder.
